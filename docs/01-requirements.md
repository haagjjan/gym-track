## Product Description
- The web application is supported on the latest Chrome and Firefox version
- The web application is used to write down workout data
- The web application is used to keep track of the progress made in the gym
- The web application is used to keep track of the weekly and montly exercise ammount


## User statements per bullet 
### The web application can be opened in the standart web browsers
- As a user I can open the webapplication from Chrome
### The web application is used to write down workout data
- As a user I can logg the types of exercises, either pre made or own exercises.
- As a user I can create my own custom exercieses.
- As a user I can logg the counts of sets, reps and RIRs per exercise.
- As a user I can logg the weights per exercise.
- As a user I can categorize the Type of exercise, into warmup and working set.
### The web application is used to keep track of the progress made in the gym
- As a user I can see the progress made for each specified exercise.
- As a user I can see all the sets (for each ex.) and their volueme (reps and weight) over a set period of time.
- As a user I can graphically see the progression of the reps and weight over a set period of time.
### The web application is used to keep track of the weekly and montly exercise ammount
- As a user I can overlook the weekly set count per mousclegroop and exercise
- As a user I can see the average weekly Set count over a distinct period of time
