# Public Beta Data Processing Inventory

Status: controller-reviewed implementation inventory. The DPIA and legal-risk self-assessment
were approved by the controller on 2026-08-10; they are not legal advice or counsel review.
Public launch remains blocked until unresolved provider transfer/retention facts are recorded
and this inventory is verified against the deployed system.

**Public transit boundary.** Every browser request and response for the public application passes
through Cloudflare. Cloudflare terminates TLS at its edge and re-encrypts traffic toward the
Tunnel, so it processes the server-bound and server-returned content described below in transit,
not only IP addresses and hostnames. The location/recipient column describes the system of record
or additional recipient; it does not exclude this common transit processor.

## Operator access

There is one explicit `ADMIN` role. The API never infers it from an email. Applicant PII is visible only in the authenticated admin queue. Database, logs, backups, email dashboards and support systems must use individual operator credentials, least privilege, MFA where available, and documented emergency access. Production provider names, regions, subprocessors, transfer mechanisms and contractual retention must replace every unresolved entry before publication.
